# 项目 HTML 文档

- [`architecture-deck.html`](./architecture-deck.html)：18 页 ROS 2 小车架构与具身岗位路线讲解，离线可打开，图形内嵌 SVG。
- [`car-explorer.html`](./car-explorer.html)：交互式小车硬件结构说明。

架构导览缩略预览：[预览-全部页面.png](./预览-全部页面.png)

## 架构导览页码

| 页码 | 内容 |
| --- | --- |
| 1–2 | 感知—决策—动作闭环的直观模型 |
| 3–8 | 本车运行链、ROS 2 边界、感知与几何、状态机、安全门、ROS 接口类型 |
| 9–11 | ROS 2 与 ros2_control 的区别、通用分层、仓库覆盖面与缺口 |
| 12–16 | 具身岗位族、招聘页面样本、VLA 与模块化栈、建议切入点、12 周学习路线 |
| 17–18 | 可核查资料与总结 |

调研方法、代码依据、外部引用和适用范围见 [`docs/embodied-robotics-architecture-research.md`](../embodied-robotics-architecture-research.md)。页面资料检索日期为 2026-11-23；岗位页面是小样本快照，不代表市场岗位比例。

使用方向键或空格翻页；按 `G` 或点左上角菜单跳页，`F` 全屏，`C` 显示页码。渲染预览命令：

```console
python3 docs/html/render_preview.py docs/html/architecture-deck.html 18 /tmp/wheeltec-deck-render 1
```
